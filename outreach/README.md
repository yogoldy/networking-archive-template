# Outreach

[Outreach register](OUTREACH_REGISTER.md) · [Home](../README.md)

This folder holds the live Markdown mini-CRM. Historical application records
belong in `../old/` and are not silently treated as current outreach.

## Working system

- The register is the compact index: Person, Organization, Role, Relationship
  path, and dated Current status.
- Each person has one linked record in `correspondence/people/` containing
  actual Conversation history, concise Preparation context, and Next steps
  whenever Leo has an outstanding action. Always consider whether correspondence
  requires action using the [action review](../docs/OUTREACH_PLAYBOOK.md#Correspondence-action-review).
- Person-specific actions live once in
  [Leo To-Do — Outreach](../docs/LEO_TODO.md#Outreach) and link both ways.
- Drafts may be developed in chat. A sent message moves into the person's
  Conversation history; superseded unsent drafts are not a permanent CRM
  layer.
- Statuses that imply external activity require Leo's confirmation or actual
  correspondence evidence. Folder placement and draft text never prove that
  contact occurred.

Before outreach work, read [local agent instructions](AGENTS.md), the
[outreach playbook](../docs/OUTREACH_PLAYBOOK.md), and
[email style](../docs/EMAIL_STYLE.md). Select relevant context from the
[Leo profile](../docs/PROJECT_MEMORY.md) and detailed evidence such as
[business-school work](../docs/BUSINESS_SCHOOL_WORK.md); no fixed story formula
applies.
