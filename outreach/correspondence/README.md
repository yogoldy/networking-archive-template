# Correspondence

[Open the outreach register](../OUTREACH_REGISTER.md) · [Home](../../README.md)

Keep one lean Markdown record per person under [`people/`](people/), using the
[thread template](agent-docs/THREAD_TEMPLATE.md). A person note contains a
Snapshot, actual Conversation history, useful Preparation context, and Next
steps. Add Open questions only when an answer materially blocks or changes an
imminent outreach decision.

## Working rules

- Snapshot fields are Person, Organization, Role, Relationship path, and dated
  Current status. Keep them aligned with the register.
- Conversation history contains only actual emails, calls, meetings, and
  introductions. Preserve exact sent/received wording when useful; never turn
  an unsent draft or internal preparation into a conversation.
- Preparation context holds relationship background, useful recipient
  research, attachment facts, meeting preparation, and links to canonical
  career evidence. Do not copy the full career story or add an evidence
  taxonomy.
- Always consider whether Leo needs to act using the
  [action review](../../docs/OUTREACH_PLAYBOOK.md#Correspondence-action-review).
  Automatically capture warranted actions once under [Leo To-Do — Outreach](../../docs/LEO_TODO.md#Outreach),
  link its checkbox to the person note, and link the note back to the To-Do
  section. Keep Next steps as `None.` only when no action remains; preserve
  unaffected outstanding work and report captured changes in the latest scan.
- A draft may remain in chat while it is being developed. Once sent, preserve
  the exact sent wording in Conversation history. Do not maintain a library of
  superseded unsent drafts in the person note.
- `Sent`, `Received`, `Replied`, and `Meeting scheduled` require Leo's dated
  confirmation or actual correspondence evidence.

The `agent-docs/` folder contains the live template and guidance. Historical
spreadsheets remain source evidence and are not synchronized with this system.
