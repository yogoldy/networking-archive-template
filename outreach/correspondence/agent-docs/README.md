# Correspondence agent docs

This folder contains the operating template and guidance used to create and
maintain person records. It is part of the live outreach system, not a person
or a conversation.

- [Thread template](THREAD_TEMPLATE.md) — starting structure for a new person
  record under [`../people/`](../people/).
- [Correspondence guide](../README.md) — lean person-note schema, conversation
  history, preparation context, and To-Do linkage.
