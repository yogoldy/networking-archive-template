# Recruiting

Historical applications, recruiting trackers, and interview preparation belong
here. Reusable identity documents belong in `../resumes/` and
`../cover-letters/`; networking messages and contact research remain in
`../outreach/`.

Application folders preserve opportunity context and do not establish that an
application was submitted or remains active. Tracker contents are source
evidence, not automatically current status. Read [`AGENTS.md`](AGENTS.md)
before working here.

See [`../docs/PROJECT_STATE.md`](../docs/PROJECT_STATE.md) and
[`../docs/ARCHIVE_OPERATING_MODEL.md`](../docs/ARCHIVE_OPERATING_MODEL.md).
