# Recruiting instructions

These rules supplement the root `AGENTS.md`.

- Never submit an application or change an external recruiting record without
  Leo's explicit instruction.
- Do not edit a tracker, application document, or status field unless the
  current task authorizes that exact change.
- Preserve each opportunity bundle and its original filenames.
- Do not infer `Applied`, `Submitted`, `Active`, `Rejected`, or another status
  from folder placement, a draft, or an old tracker row.
- Require submission evidence or Leo's direct confirmation before recording a
  completed application action.
