# Legacy and unclassified material

This is the review and quarantine boundary.

- `system-metadata/` contains 29 Finder metadata, Office lock/temp, or shortcut
  items from the migration. They are retained for inventory continuity but are
  not substantive career evidence.
- `needs-review/` is reserved for future material that cannot be classified
  without guessing; it is empty at migration completion.

Do not delete quarantine items, infer career status from them, or promote an
item into a functional folder without review. This single README serves both
the top-level and boundary guidance roles defined by the reorganization plan.
