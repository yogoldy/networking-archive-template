# Recruiting trackers

This folder contains six preserved workbook candidates, including a template.
No canonical historical tracker is needed. Original spelling, formulas, content,
and status values must remain unchanged unless Leo authorizes a specific edit.

Do not merge the workbooks or treat their most recent-looking rows as current
status. The workbooks remain historical evidence; no canonical historical
workbook is needed. Current outreach is tracked in the
[`outreach register`](../../outreach/OUTREACH_REGISTER.md).
